## 10. 本次测试发现并修复的问题

### Bug 1: login.tsx 硬编码 API 端口 (已修复) ⚠️→✅

**问题**: `pages/login.tsx:20` 硬编码 `http://127.0.0.1:8000`, 不使用 `API_BASE` 环境变量
**影响**: 后端非 8000 端口时, 登录/注册页面无法工作
**修复**:
- `lib/api.ts`: 导出 `API_BASE` 常量
- `pages/login.tsx`: import `API_BASE`, 用 `${API_BASE}/api/auth/${mode}` 替代硬编码
**验证**: build 产物中 login 页面不再包含 8000 端口

### 配置 1: 前端 .env.local 缺失 (已创建) ⚠️→✅

**问题**: 前端无 `.env.local`, 使用默认 8000 端口, 但后端运行在 8766
**影响**: 前端显示"模拟模式 — 交易所连接不可用"
**修复**: 创建 `frontend/.env.local`:
```
NEXT_PUBLIC_API_URL=http://127.0.0.1:8766
NEXT_PUBLIC_WS_URL=ws://127.0.0.1:8766/ws/ticker
```

### 配置 2: .env.example 不完整 (已补全) ⚠️→✅

**问题**: `.env.example` 只有 `NEXT_PUBLIC_API_URL`, 缺 `NEXT_PUBLIC_WS_URL`
**修复**: 补全 WS URL 配置

## 11. 已知的配置问题 (非代码 bug)

### API Key 不匹配 testnet 环境

**现象**: 后端日志显示 `APIKey does not match current environment. code=50101`
**原因**: `.env` 中 `EXCHANGE_TESTNET=true` 但 API key 可能是实盘 key
**影响**:
- 公开行情接口正常 (ticker/ohlcv/orderbook)
- 鉴权接口失败 (balance/open-orders) — 系统优雅降级, 返回空数据
**解决**: 用户需配置正确的 OKX testnet API key, 或切到实盘模式
