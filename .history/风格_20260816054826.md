# 终端极客风 Terminal Aesthetic

> **你可能会说**
> 像黑客终端那样：黑底绿字、等宽字体、敲命令的感觉。

**终端极客风是一种借用命令行界面元素的网页视觉风格**

它常用等宽字体、提示符、命令输出、ASCII 分隔线和有限色彩，适合开发者工具与 API 文档。命令应保留为可复制的真实文字，整页也不必全部做成黑底绿字。

## 设计原则 · Principles

- 等宽字体用于命令、数据和短标签，长正文保持易读
- 建立克制的基础色，让命令内容始终清楚
- 提示符和状态符号只用于帮助识别结构
- ASCII 分隔线可以组织内容，但不能增加阅读负担
- 闪烁光标只作轻量提示，并响应减少动效设置

## 什么时候用
- 命令行工具官网，让网页延续产品语言
- 开发者文档首页，强调目录和命令示例
- API 与云服务页面，展示状态和技术信息
- 工程团队招聘页，面向熟悉命令行的受众

## 什么时候不用
- 面向非技术用户却不解释终端符号
- 暗色背景配低对比、小字号正文
- 把命令做成图片，导致无法复制和搜索
- 同时加入大量不相关的玻璃和拟物材质

## 组成结构 · Anatomy

### 等宽字体 Monospace

用于命令、路径和数据对齐；长正文不必强制使用

### 克制色板 Palette

以少量基础色突出输出状态，同时保证对比度和状态含义

### $ 提示符 Prompt

提示符可标明命令上下文；关键操作、状态和错误仍需文字或稳定图标

### ASCII 分隔线 ASCII Divider

────── ┤标题├ ──────,字符代替图形分隔

### 闪烁光标 Blink Cursor

可作为装饰性运行提示；不要持续干扰阅读，并支持减少动效
